Global biodiversity and environmental data are abundant and free, but pulling useful insights from them often requires data science and GIS expertise that most decision-makers, conservation practitioners, and community members don't have. The gap is usually not in data availability, but in legibility.

My work in this area focuses on building web tools that lower the technical barrier between people and the data they need. Some projects use AI to enable plain-language queries, while others take a more traditional dashboard approach. What ties them together is a commitment to meeting users where they are and designing around the questions they actually want to ask.

Current projects include:
1. An AI-powered web tool (in development, supported by a Google.org proposal) that lets urban planners and city agencies ask plain-language questions of biodiversity data across sources like GBIF, iNaturalist, and OpenStreetMap. This project uses open-weight language models and a custom Model Context Protocol (MCP) server, and is being piloted with the ReImagine SF coalition.
2. A fire followers dashboard built in collaboration with the California Native Plant Society, which turns data from their Fire Followers iNaturalist campaign into an interactive tool for decision-makers and community scientists.
3. An Ecology of a Living Archive (EoAL) demo that makes global community science biodiversity data explorable without requiring specialized software.

A common principle across these projects is that they should be open-source and built on open data standards, so that users can comment on and interrogate the methods behind the tools they rely on.
